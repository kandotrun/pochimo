# MVP Spec: ペット日報AI

## 目的
「留守中にペットがどう過ごしていたか」を、古いスマホ1台で毎日要約する。

## 初期ユーザー体験
1. 古いスマホを充電しながらペットが映る場所に置く
2. Webページを開く
3. カメラを許可して開始
4. 夜に日報を見る

## 最初の価値仮説
ペットカメラは「見られる」が、飼い主は一日中見返さない。AIが要点だけ日報化すれば安心に変わる。

## MVP指標
- 1日分の日報を読んで「明日も欲しい」と思うか
- 水/ごはん/トイレなどの注目エリア指定が必要か
- 毎日か、外出日だけか
- 980〜1,980円/月で払うか

## 初期価格仮説
- 個人β: 980円/月
- 正式: 1,980円/月
- ペットホテル/シッター: 9,800〜19,800円/月

## 注意
医療判断はしない。「気になる変化」「確認ポイント」に留める。
